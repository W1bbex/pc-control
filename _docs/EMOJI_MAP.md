## 2. Использование в коде

Все иконки загружаются динамически из `resources/icons.json` (или `vds_bot/resources/icons.json`):

```python
import json
from pathlib import Path

def get_icon(key: str, default: str = "") -> str:
    path = Path(__file__).resolve().parent / "resources" / "icons.json"
    if path.exists():
        try:
            with open(path, "r", encoding="utf-8") as f:
                return json.load(f).get(key, default)
        except Exception:
            pass
    return default
```

### В тексте сообщений (HTML parse_mode):
```html
<tg-emoji emoji-id="5330499003580721030">💻</tg-emoji> <b>PC Control</b>
<tg-emoji emoji-id="5330478284658488376">👤</tg-emoji> <b>Сессия</b>
<tg-emoji emoji-id="5330077297921795474">⚡</tg-emoji> <b>Железо</b>
<tg-emoji emoji-id="5330394360997517972">📁</tg-emoji> <b>Накопители</b>
```

### На кнопках Inline Keyboard:
```python

    "text": "Питание",

    "icon_custom_emoji_id": ICONS.get("power"),
    "callback_data": "power_menu"

```

## 3. Архитектурный регламент для агентов

1. **Единый стикерпак:** В проекте `@your_pc_bot` используется **строго один** канонический набор — `pc_icons_pack`. Запрещено создавать побочные или сторонние паки для разных фичей.
2. **Никакого хардкода:** Все ID эмодзи должны читаться из `resources/icons.json` (или `vds_bot/resources/icons.json`). В коде не должно быть жестко зашитых сторонних ID.
3. **Формат и стиль:** Основная масса иконок — векторный `.tgs` (Lottie), `needs_repainting: True`, толщина контура 5.5%, прозрачный фон. Для логотипов операционных систем (`linux`, `windows`) используется `needs_repainting: False` для сохранения оригинальных фирменных цветов. Никаких растровых жирных клякс.
4. **Консоль и статусы:** Для статуса выполнения задач использовать часы `clock` (`5330473500064912704`), для статуса готовности — `status_active` (`5330273230034871570`), для шапки консоли — `terminal` (`5330563608478787902`).
