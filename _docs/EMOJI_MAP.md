# Карта эмодзи UI Icons (`TELEGRAM_ICONS_EMOJI_PACK`)

> **Канонический адаптивный векторный стикерпак Telegram-бота**  
> **Владелец:** Telegram ID `<OWNER_TELEGRAM_ID>`  
> **Формат:** Векторная анимация Lottie `.tgs` (`needs_repainting: True`)  
> **Стиль:** Официальная эталонная база TgAndroidIcons (129 чистых отобранных иконок) + 8 священных цветных и системных иконок.

## 2. Использование в коде

```python
from vds_bot.telegram_ui import ICONS

power_emoji = ICONS.get("power")
# Рендеринг в HTML сообщении:
text = f"<tg-emoji emoji-id='{power_emoji}'>⚡</tg-emoji> Запуск компьютера"
```
